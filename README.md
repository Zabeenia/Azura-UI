# ❄️ Azura UI
### Aurora Ice Edition
*A crystal-inspired Minecraft UI featuring frosted glass, magical skies and a love for blueberries.*

---

## ✨ About

Azura UI is a collection of themed editions sharing the same design philosophy while offering different visual identities.

Aurora Ice Edition is the original release of the collection.

---

## 🌌 Why "Azura"?

The name "Azura" reflects the pack's visual identity:

- crystal glass
- magical skies
- shimmering colors
- calm lighting

Rather than completely redesigning Minecraft, Azura gently enhances the familiar interface with a calm and cohesive aesthetic.

---
